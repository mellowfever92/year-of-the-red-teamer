📖 About Hexadecimal Encoding

Hexadecimal (base-16) encoding represents binary data using 16 distinct symbols: 0-9 for values 0-9, and A-F for values 10-15. Each byte (8 bits) is represented by exactly two hexadecimal digits.

Why Hex Encoding in Security?

  • Binary Compatibility: Hex can represent any binary data, including non-printable characters
  • Compact Representation: More compact than binary, more readable than raw bytes
  • Technical Legitimacy: Natural in firmware, memory dumps, and low-level systems
  • Pattern Matching: Enables precise binary signature detection
  • Obfuscation: Can hide text content while appearing technical
🎓 Security Context: In Week 2 of our curriculum, we explore how hex encoding can bypass security filters that only check plaintext patterns. Hex-encoded strings look "technical" and often pass through validation layers that would block plaintext equivalents.

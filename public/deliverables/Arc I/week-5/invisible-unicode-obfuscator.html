📚 Technical Reference

Zero-Width Characters

Zero-width characters are invisible Unicode characters that have no visual representation but exist in the text stream. They are commonly used for text formatting and language support but can be exploited for obfuscation.

Character Code Point Name Purpose
ZWSP U+200B Zero Width Space Word break opportunity
ZWNJ U+200C Zero Width Non-Joiner Prevents ligature formation
ZWJ U+200D Zero Width Joiner Forces ligature formation
ZWNBSP U+FEFF Zero Width No-Break Space Byte order mark (deprecated)

Mongolian Vowel Separators

The Mongolian Vowel Separator (MVS) is an invisible formatting character used in traditional Mongolian script. It's particularly effective for obfuscation because many systems don't normalize or detect it.

Character Code Point Name Detection Difficulty
MVS U+180E Mongolian Vowel Separator High (rarely filtered)

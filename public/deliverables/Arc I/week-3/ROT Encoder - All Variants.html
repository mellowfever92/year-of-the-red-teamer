📋 What is ROT Cipher?

ROT-N (Rotation-N) is a simple character substitution cipher that rotates each letter N positions forward in the alphabet.

For example:

  • ROT1: A→B, B→C, ..., Z→A
  • ROT13: A→N, B→O, ..., M→Z, N→A, ..., Z→M
  • ROT25: A→Z, B→A, C→B, ..., Z→Y (one position back)

Red Team Application: ROT ciphers bypass shallow regex-based content filters that look for exact string matches. While easily reversible, they demonstrate how LLMs can decode obfuscated instructions after tokenization, even when surface-level pattern matchers fail.

🔍 ROT13 Special Property

ROT13 is its own inverse: Applying ROT13 twice returns the original text. This makes it historically symmetric and explains its cultural significance in internet obfuscation.

Character Handling: This encoder preserves non-alphabetic characters (numbers, spaces, punctuation). Only A-Z and a-z are rotated.

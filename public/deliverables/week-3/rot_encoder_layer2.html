🎯 Layered Encoding Strategy

  • Layer 1 (ROT-N): First obfuscation layer using character rotation
  • Layer 2 (Base64/Hex): Second encoding layer that appears as random data
  • Attack Vector: Dual-layer encoding defeats simple pattern matchers and string searches
  • Base64: Binary-to-text encoding, compact representation, common in data transmission
  • Hex: Hexadecimal representation, longer but pure ASCII, debugging-friendly
  • Detection Evasion: Multi-layer approach requires decoding chain to analyze content
  • Red Team Use: Paste encoded payload → LLM decodes both layers → semantic meaning extracted
